# WordPress.org Assets

Copy these files to the WordPress.org SVN repository's top-level `assets` directory when preparing a public release:

- `banner-772x250.png`
- `banner-1544x500.png`
- `icon-128x128.png`
- `icon-256x256.png`

The banner and icon files use the approved AIO logo and AIO Sentinel product name. They are not required in the customer installation ZIP.

Before public release, add `screenshot-1.png`, `screenshot-2.png`, and matching captions to `readme.txt`. Screenshots must show real product workflows and contain no customer or credential information.
