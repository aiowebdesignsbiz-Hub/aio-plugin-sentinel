# Support Process

For configuration help or a review-level alert, provide the AIO Sentinel version, WordPress version, the JSON evidence export, and the exact finding path. Do not send administrator passwords, database exports, or unredacted credentials.

For a critical finding, preserve the evidence, avoid activating or updating the affected plugin, and use the controlled quarantine workflow only after a qualified administrator reviews the result. If the site is actively showing a fake verification screen, restrict administrative access and contact the hosting provider as part of incident response.

Potential security vulnerabilities in AIO Sentinel itself belong in the private process described in [SECURITY.md](SECURITY.md).

Once the public plugin listing is live, normal support requests should be opened through its WordPress.org support forum. The public forum must not be used for credentials, active malware samples, or vulnerability details.
